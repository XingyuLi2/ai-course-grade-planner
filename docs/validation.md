# 评测指标：课程成绩规划 Demo

本文件定义课程成绩规划 Demo 的体验、评分规则提取、目标试算与分数持续更新的评测方法。评测围绕一条主线：学生能否从课程材料得到可核对的成绩表，试算目标要求，并在出分后继续更新。

截至2026-11-25，已有93项自动检查通过；浏览器已完成部分核心操作走查，完整验收待补。真实模型提取和同学任务观察待执行。当前演示使用配套材料的模拟提取。

## 1. 评测目标

1. 材料生成成绩表后，学生能找到核对、修正和预计试算入口。
2. 实际与预计成绩始终分开，更新一项后保留其他成绩。
3. 目标差距、唯一未知项要求和额外及格条件计算正确。
4. 规则提取保留来源、缺失、冲突和未支持内容。
5. 已出成绩修改经过核对确认，取消后保留原记录。
6. 再次打开课程后，学生能继续完成下一次更新。

## 2. 产品体验指标

以下指标用于后续同学任务观察，目前均待测。每位参与者分别记录完成情况、耗时和求助，再按实际人数汇总。

### 2.1 核心任务完成率

**定义：** 完成指定路径的人数／开始该任务的人数。

```text
选择演示材料 → 生成成绩表 → 核对规则
→ 填写预计成绩 → 解释目标要求
```

观察是否能自行找到下一步，以及是否理解页面中的“模拟提取”和“预计成绩”。这项指标用于定位流程中断点。

### 2.2 二次更新完成率

**定义：** 成功恢复已保存课程、录入新成绩并读出目标要求的人数／执行该任务的人数。

任务从再次打开已有课程开始。记录恢复是否成功、是否重复输入旧信息、是否误改其他成绩，以及从打开页面到读出结果的时间。这是持续保存是否服务于真实使用场景的重点。

### 2.3 结果理解正确率

**定义：** 正确解释指定结果的人数／回答该问题的人数，各题单独统计。

题目围绕三个含义：

- 哪些分数已经拿到，哪些只是预计？
- 多项剩余时的整体百分比表示什么？
- 总分达到目标后，额外及格要求是否也已满足？

问题解释错误时，结合页面位置和原话分析原因，再调整提示或信息顺序。

### 2.4 成绩修改操作表现

逐人记录“修改后取消”和“修改后确认”两项任务：原值是否保留、新值何时生效、是否需要求助、是否误清其他成绩。先统计实际发生次数，再决定是否需要汇总比例。

## 3. AI规则提取质量指标

独立模型实验使用固定 [Prompt v0.1](../prompts/extract-rules.md)、[输入与人工答案](../evaluation/cases.jsonl) 和 [记录模板](../evaluation/run-template.md)。当前5例均为合成输入，`run_status` 均为 `not_run`；下列指标尚无模型结果。

| 指标 | 定义与记录方法 | 重点字段 |
| --- | --- | --- |
| 字段正确率 | 与人工答案一致的字段数／参与比对的标注字段数；同时列出分子、分母和错误字段 | 权重、原始满分、实际／预计、目标、通过线、最低分条件 |
| 整例正确率 | 所有必需字段与规则问题均处理正确的案例数／已运行案例数 | 完整课程及缺失、冲突、未支持规则 |
| 来源支持率 | 引用原文能支持其值的非空事实字段数／输出的非空事实字段数 | 原文片段、材料编号、截图位置 |
| 缺失信息处理正确率 | 正确留空并提出具体问题的缺失字段数／人工标注的缺失字段数 | 未给满分、通过线、成绩步长、门槛信息 |
| 结构可用率 | 符合候选字段结构及类型的输出数／已运行输出数 | 十进制字符串、null、数组、状态字段 |

比对允许等价十进制表达，区分空值与零、原始分与百分比、`>` 与 `>=`。首次输出、追加提示后的输出和人工修正结果分别保留。真实课程、同源衍生和合成输入分别统计。

## 4. 关键风险指标

风险指标用于发现会改变算分结论的问题。当前模型实验待执行，先按案例记录问题类型与次数。

| 风险 | 评测定义 | 预期处理 |
| --- | --- | --- |
| 最低分要求遗漏或误读 | 对象、运算符、阈值、单位或组合关系出错的案例数／含相关要求的案例数 | 保留每条要求与原文依据，单独核对 |
| 无依据新增信息 | 每例统计输入未提供却被补出的事实字段 | 未给满分、通过线或等级阈值时留空并询问 |
| 来源冲突被覆盖 | 被自动选定一方的冲突字段数／人工标注的冲突字段数 | 同时保留候选值与来源，交由学生确认 |
| 未支持规则被遗漏 | 未被保留和标记的特殊规则数／人工标注的特殊规则数 | 保留原文、说明支持范围，暂停正式计算 |
| 实际与预计混淆 | 将预计当实际、重复计分或覆盖实际的案例数／涉及两类成绩的案例数 | 分别提取，同项计算优先使用实际值 |
| 提取越过确认 | 输出已确认状态或直接给正式通过结论的案例数／已运行案例数 | 输出候选数据，进入学生核对环节 |

这些问题发生后需要逐例分析，即使总字段正确率较高也单独呈现。分母为零时记为“不适用”。

真实模型实验可通过已有对话工具手工提交固定Prompt独立开展。记录材料类型、模型可见名称、Prompt版本、上下文、原始输出和人工比对结果；等待时间和成本按实际可取得的信息填写。网页目前没有调用该Prompt。
