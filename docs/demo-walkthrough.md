## 3. 约90秒讲解顺序

1. 说明产品用于持续记录课程成绩，当前提取只对配套材料模拟。
2. 展示材料入口、成绩表与生成后修正的位置。
3. B预计30时，解释期末72与实际24之间的关系。
4. 录入B实际32，展示核对原值与新值、最终确认，再解释实际40和期末70。
5. 拟改31后取消并刷新，展示原32保留。
6. 说明已完成的计算与核心操作验证，以及待补的模型实验、同学观察和完整浏览器验收。
