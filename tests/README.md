所有输入均为合成数据。[计算契约](../docs/calculation-spec.md) 给出12个人工基准，[fixtures.mjs](fixtures.mjs) 转录输入，[calculation.test.mjs](calculation.test.mjs) 硬编码独立人工答案；不使用待测程序生成期望值。

## 一次运行全部检查

在产品仓库根目录（包含 `serve.py`、`dist/`、`tests/` 的目录）运行，需要 Node.js。本轮实际使用 Node v24.22.3；没有安装第三方依赖。

```bash
node --experimental-vm-modules tests/run-all.mjs
```

需要更新随仓库保存的结果时，显式添加 `--write`：

```bash
node --experimental-vm-modules tests/run-all.mjs --write
```

[run-all.mjs](run-all.mjs) 复用现有五组检查，失败时退出码为1；`--write` 写入各组 `latest-*-results.json`，保留 UTC 时间、Node版本、平台、命令与方法。Node VM 的实验性提示来自运行环境，不是失败；应以逐组结果和退出码判断。

## 浏览器运行部分模块检查

在相同产品仓库根目录启动：

```bash
python3 serve.py
```

打开 [检查页](http://127.0.0.1:8000/tests/)。该页执行计算52、存储13、成绩编辑11，共76项，显示逐项结果；另外17项依赖Node VM，不能在这里运行。存储仍是内存替身，即使此页在浏览器中全部通过，也不能代替产品页面刷新恢复、原生弹窗、焦点和视觉验收。

服务只提供产品目录。关闭服务按 `Ctrl+C`，不要将包含私人材料的上级工作目录当作静态服务根。

## 检查覆盖

- 不同原始满分与权重、实际零分与未知成绩、多个未知项整体要求和唯一未知项倒推。
- 总分已够、目标不可达、无剩余权重、零权重项目仍有最低分要求。
- 总分目标与额外及格要求分开判断；实际、预计和待定状态区分。
- 实际优先于预计；未出分项无效预计只阻断依赖它的试算，不影响实际概览；计算函数不修改输入。
- 权重合计异常、缺失字段、未确认规则、冲突、严格 `>` 与暂不支持规则。
- 数学下界、最低分数四位小数向上显示、明确的整数／半分步长与回代。
- 规则修正页各分类的错误定位，不因隐藏分类或切换页面漏掉问题。
- 存储往返、损坏／未知版本保留、空间或权限失败、多标签冲突、重置及失败保护。
- 已出成绩草稿、确认与取消、越界拦截、旧值冲突、只清同项预计、保留其他成绩。
- 配套材料生成成绩表、核对、预计保存、改名、规则草稿保存／取消、自有材料仅预览、替换取消。
- 保存失败后重试不提前写入未确认规则草稿；file打开方式和模块加载失败提示。
